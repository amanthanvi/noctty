Architecture review · 2026-07-23

One terminal accessibility session. One window-theme adapter.

Top recommendation: replace split lifecycle ownership with two deep modules whose small interfaces preserve semantic correctness across focus, repaint, preview, rollback, and High Contrast.

Terminal contract drift

TextPattern2 exposes a caret while legacy TextPattern advertises no selection. Snapshot freshness is coupled to repaint/listener policy.

Theme ownership gap

The model previews Dark, but host invalidation is conditional and Settings paints unconditional system colors.

High-leverage seam

Both defects cross stable boundaries with multiple callers and sensitive policy: real candidates for module depth and locality.

Before: shallow ownership, hidden coupling

flowchart LR R[Renderer .render] --> S[Surface.refreshTerminalUiaText] Q[UIA query] --> P[TerminalProvider] P --> C[TerminalUiaContext] C --> M[Posted HWND message] M --> S F[Surface focus] --> E[FocusChanged event] S --> C C --> P T[Settings combo] --> X[Generic preview callback] X --> A[App.reconfigureTheme] A --> H[Host DWM + brushes] A --> I[Settings invalidate] I --> G[GetSysColor paint]

The focus path bypasses snapshot refresh. The Settings path invalidates pixels that are recomputed from unchanged system colors.

After: deep modules, explicit interfaces

flowchart LR R[Terminal mutation/repaint signal] --> TAS F[Focus/activation] --> TAS Q[WM_GETOBJECT/query] --> TAS Z[Timer/detach] --> TAS subgraph TAS[TerminalAccessibilitySession] C[Snapshot cache + refresh policy] K[Canonical caret] P[UIA provider adapter] V[Text/caret events + spoken-output queue] C --> K --> P C --> V end T[Typed theme preview/revert] --> WTA HC[High Contrast state] --> WTA subgraph WTA[WindowThemeAdapter] D[DWM attributes] B[Semantic brushes/control theme] I[Complete invalidation] end WTA --> H[Terminal host] WTA --> S[Settings window + controls]

Renderer repaint is an input, not the accessibility ownership boundary. High Contrast is an explicit branch, not an incidental color source.

TerminalAccessibilitySession interface

  • getObject — provider acquisition and initial snapshot
  • onTerminalMutation — coalesced semantic refresh and bounded new-output speech
  • onFocus — refresh before focus publication
  • onTimer / detach — scheduling and lifetime

WindowThemeAdapter interface

  • resolved theme + window kind + High Contrast input
  • DWM/native-control implementation hidden inside
  • semantic brush cache and teardown ownership
  • known-scope repaint after resource replacement
