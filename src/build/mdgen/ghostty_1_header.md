# NAME

**koreterm** - koreterm terminal emulator

# DESCRIPTION

koreterm (formerly winghostty) is a GPU-accelerated terminal emulator for
Windows. It embeds the terminal core from the Ghostty project inside a
native Win32 application, adding tabs, splits, session restoration, a
native settings window, and a keyboard-driven command palette.

koreterm is a fully standards compliant terminal emulator that aims to
remain compatible with all existing shells and software, while exposing
the modern, opt-in terminal features pioneered upstream so CLI tool
developers can build more feature rich, interactive applications. You
can use it as a drop-in replacement for your existing terminal emulator.

koreterm is an independent project and is not affiliated with or endorsed
by the Ghostty non-profit.
