## Design Context

### Users

Windows developers evaluating terminal emulators and forks. They arrive skeptical of SmartScreen warnings, unsigned installers, and overclaimed parity. They need a fast read on what ships today, how to install, and whether the project is credible.

### Brand Personality

**Native · credible · precise**

### Aesthetic Direction

**Windows craft** — Fluent-like surfaces, Segoe-forward UI typography, MS four-color accents used sparingly (dots, punctuation, one primary control). Dark-primary theme matching terminal use; light mode polished for daytime sharing. Anti-references: cyan-on-dark AI slop, purple gradients, gradient text, identical icon+heading card grids, thick side-stripe callouts.

### Typography

| Role | Stack |
|------|--------|
| Display | Bricolage Grotesque (headlines) |
| Body | "Segoe UI Variable", "Segoe UI", system-ui, sans-serif |
| Mono | JetBrains Mono, Consolas, ui-monospace |

### Design Principles

1. **Accents earn their place** — MS colors on dots and micro-highlights, not ambient neon glows.
2. **Terminal demo proves claims** — the mock window shows real install paths and guardrail-accurate copy.
3. **Copy is defensible** — every claim must pass `scripts/check-site-copy.ps1`.
4. **Motion respects preference** — `prefers-reduced-motion` disables typewriter autoplay.
5. **Conversion is obvious** — Download latest (primary), Scoop (secondary), GitHub (tertiary).
