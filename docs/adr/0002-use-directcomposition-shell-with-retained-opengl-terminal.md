# Use a DirectComposition shell with the retained OpenGL terminal

noctty will replace GDI application chrome incrementally with a native DirectComposition, Direct2D, and DirectWrite shell while retaining the proven WGL/OpenGL terminal renderer. The shipped boundary owns recoverable D3D11/DirectComposition targets and transparent DPI-sized surfaces for top-level Host windows. Host banner and operation-feedback text is the first production DirectWrite zone; it falls back to GDI whenever drawing, commit, or device recovery fails. Remaining chrome stays on GDI until it passes the same isolated-zone gates. This isolates shell polish and refresh-aware composition work from Ghostty's terminal rendering pipeline, avoiding the reliability and parity risk of rewriting both stacks at once.
