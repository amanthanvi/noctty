- 2026-11-11: A polish pass on noctty.com (SITE-POLISH-COUNCIL) found five traps. (1) JetBrains Mono's `calt` joins `-<`, `>-` and `--` into arrow and long-dash glyphs, so `.\noctty-<version>-windows-<arch>-setup.exe` and `--id` misread in the About and install commands. The font's GSUB features are only `calt`, `ccmp`, `frac` and `locl` (read with fontTools), so `liga` alone does nothing. `code`, `pre` and `.nc-cmd` set `"calt" 0` and `font-variant-ligatures: none`; terminal windows keep ligatures, because the app draws them (`HEAD → main` in the captures). (2) `overflow-wrap: anywhere`, which the 2026-10-16 WinGet entry below gave an inline command to stop a 320 px overflow, also splits a command anywhere (`--`/`depth`, `SELF_SI`/`GNED`, `scoop-`/`noctty`). Commands now use `break-word`, hyphenated flags and file names sit in `.nc-nobr` spans, a URL breaks at its `<wbr>`, and a token longer than the line scrolls its block. No page overflows from 320 to 1920 px (headless Chrome, all three pages). Tests that read command text out of the markup strip those spans first (the verifier regex in `trust.test.mjs`, `proofBlocks` in `install.test.mjs`). (3) The fake `document.querySelectorAll` in `site/tests/app.test.mjs` returned the 404 path slots for every selector, so the first new `querySelectorAll` in `app.js` (the sideways-scrolling captures, `[data-nc-pan]`) crashed both 404 tests; it now answers only `[data-nc-lost-path]`. (4) Many page loads from one machine get 403 from `api.github.com` (unauthenticated rate limit), and `version.js` keeps the compiled version; a capture run that logs `Failed to load resource: 403` is seeing that, not a site error. (5) `test/windows/flagship/contracts/Contracts.92-Site.ps1` pins `SITE_PAGES` in `scripts/build-site-assets.mjs` as a literal pattern ("SHA-256 cache keys cover every local script and stylesheet referenced by each page"), so giving `why-noctty.html` the `install.js` module passed every Node test and failed Windows Checks; the contracts run only under pwsh, which this machine lacks. Rule: keep ligatures off outside terminal windows, wrap commands only at spaces and `<wbr>`, make a fake DOM's queries selector-aware, and when a page gains or loses a local asset, change `SITE_PAGES`, that contract pattern and the `scripts/build-site-payload.ps1` allowlist together.
