- 2026-10-15: A doc-drift sweep (PKG-63) found that a statement copied from a test is only as true as the options the test runs with. `docs/windows.md` said `ctrl+m`, `ctrl+i`, `ctrl+[` "have no C0 byte" and send `CSI <codepoint>;5u`; the audit's fix kept the CSI u half because `win32/input.zig`'s issue-178 test expects `\x1b[109;5u`. That test runs the default encoder. The shipped path sets `windows_legacy` (`key_encode.zig`, active only while the Kitty flags are 0), where Ctrl+m is CR, Ctrl+i is TAB and Ctrl+[ is ESC (pinned by "legacy: Windows console control table"), and under ConPTY's Win32 input mode the keys are console key records; CSI u is what an application that enables the Kitty protocol gets. Find which `Options` a test passes before quoting its bytes.
