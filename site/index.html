A native terminal for Windows.

Noctty runs Ghostty's terminal core inside a Win32 app. It has tabs, splits, and a command palette. Close it and open it again and the layout is still there.

Tabs and splits

Session restoration

Close Noctty and open it again to the same windows, tabs, and split layout. Working directories, profiles, and explicit titles come back with them. Each pane can run its own shell: PowerShell, cmd, Git Bash, or WSL if you opt in.

Universal palette

One shortcut opens a list of everything you can do: actions, tabs, panes, profiles, themes, settings. Matching is fuzzy, so a partial name finds the entry. Nothing in the list needs the mouse.

Native settings

There is a settings window for appearance, shells, keybindings, privacy, and updates. It stages your changes and writes only the lines you touched, so comments and ordering survive. The file is at %LOCALAPPDATA%\noctty\config.ghostty if you would rather edit it directly.

How it's built

Ghostty does not ship a Windows app today, so Noctty builds one around Ghostty's terminal core. Parsing, fonts, rendering, input, and shell integration are shared with upstream and track it closely.

The Win32 runtime, windowing, tab and split management, the settings window, and the updater are this fork's own work. Noctty is an independent project and is not affiliated with the Ghostty non-profit.

The project moves quickly, so the release notes are worth reading before you update. An update is staged only after its signature and checksum verify, and then it waits for you.

Accessibility is partial, not complete. Terminal text, focus, selection, the command palette, and native settings controls have UI Automation coverage today. Broader per-widget and screen-reader validation is still in progress.
