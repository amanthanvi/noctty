A native terminal for Windows.

Noctty runs Ghostty's terminal core inside a Win32 app. Tabs, splits, the whole shebang.

What ships

  • Authenticode signed, with a self-signed certificate.
  • One update check per launch, switchable off. No telemetry.
  • MIT. Source and release scripts are public.

Using it

Session restoration

Close Noctty and open it again to the same windows, tabs, and split layout. Working directories, profiles, and the titles you set explicitly come back with them. Panes can each run their own shell: PowerShell, cmd, Git Bash, or WSL if you opt in.

Universal palette

One shortcut opens a fuzzy list of actions, tabs, panes, profiles, themes, settings. Matching is fuzzy, so a partial name finds the entry, and nothing in the list needs the mouse.

Native settings

A settings window for appearance, shells, keybindings, privacy, and updates. It writes only the lines you touched, so your comments and ordering survive. The file is at %LOCALAPPDATA%\noctty\config.ghostty if you would rather edit it directly.

How it's built

Ghostty does not ship a Windows app today, so Noctty builds one around Ghostty's terminal core. Parsing, fonts, rendering, input, and shell integration are shared with upstream and track it closely.

The Win32 runtime, windowing, tab and split management, the settings window, and the updater are this fork's own work. Noctty is an independent project and is not affiliated with the Ghostty non-profit.

The project moves quickly, so the release notes are worth reading before you update. An update is staged only after its signature and checksum are verified, and then it waits for you.

Accessibility is partial, not complete. Terminal text, focus, selection, the command palette, and native settings controls have UI Automation coverage today. Broader per-widget and screen-reader validation is still in progress.
