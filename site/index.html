    Session restoration

    Close it Friday, open it Monday. Start Noctty again, even after a reboot, and the same windows, tabs, and splits come back, each pane in the folder its shell last reported, with its profile and any title you set.

    Programs start fresh, SSH panes reopen as your default shell, and a window opened from Explorer, the jump list, or with -e stays out of the saved session. For the old output too, set window-save-state-scrollback and it comes back as plain text, marked as restored.

    Universal palette

    Ctrl+Shift+P, then type. Actions, tabs, panes, profiles, themes, and settings sit in one fuzzy list, and it remembers what you ran recently.

    Narrow it with a prefix: @ for tabs, ~ for profiles, % for themes, > for actions.

    • Ctrl+Shift+P Open the palette

    Native settings

    Leaves your comments alone. A real Windows settings window for appearance, the terminal, shells, privacy, and updates. Saving rewrites only the keys you changed in %LOCALAPPDATA%\noctty\config.ghostty and keeps every other line as it was.

    Or edit the file by hand and reload it.

    • Ctrl+, Open settings
    • Ctrl+Shift+, Reload config

    Also in the box

    • SSH hosts

      Each named host in ~/.ssh/config becomes a profile that runs your own ssh.

    • Undo a closed tab

      Ctrl+Shift+Z within five seconds of closing a tab brings it back with its panes.

    • Search the scrollback

      Ctrl+Shift+F opens a docked search with regex, case, and whole-word modes.

    • Open noctty here

      The installer adds it to Explorer's folder menu.

    • Jump list

      Installed copies list recent folders and profiles on the taskbar icon.

    • Quick terminal

      Bind toggle_quick_terminal to a global: hotkey to summon a terminal from any app while Noctty runs.

    Built on Ghostty. Not by Ghostty.

    Noctty takes Ghostty's terminal core, which handles parsing, fonts, rendering, and input, and takes in upstream changes in planned merge windows, normally after each Ghostty release. The Win32 runtime, windowing, tabs and splits, the settings window, and the updater are Noctty's own work.

    Noctty is an independent project and is not affiliated with Ghostty. Who maintains it and what has been measured are on the About page.

    SmartScreen will warn you. Here's why.

    Releases are signed, but with a self-signed certificate, so Windows can't name a publisher and SmartScreen never builds a reputation for it. The About page shows how to check a download's checksum and signature before you run it.

    Accessibility

    Accessibility is partial, not complete: terminal text, focus, selection, the palette, and the settings controls expose UI Automation, and no screen reader has been validated against a release build yet.

    Install

    Download for Windows

    WinGet Recommended

    > winget install --id AmanThanvi.noctty -e

    Runs the signed installer. It does not add noctty to PATH.

    Scoop Puts noctty on PATH

    > scoop bucket add noctty https://github.com/amanthanvi/scoop-noctty
    > scoop install noctty/noctty

    The bucket is amanthanvi/scoop-noctty on GitHub.

    Chocolatey Runs the installer

    > choco install noctty

    chocolatey.org reviews each version before listing it, so a new release can reach it after the other channels. It does not add noctty to PATH.

    Installer or ZIP From GitHub Releases

    Take the signed installer or the portable ZIP from the latest release. For a portable copy, add an empty noctty.portable file next to noctty.exe.
